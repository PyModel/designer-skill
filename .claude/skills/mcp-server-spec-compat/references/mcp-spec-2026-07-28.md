# MCP spec 2026-07-28 delta for designer-skill-mcp (checked 2026-11-12)

Sources: https://modelcontextprotocol.io/specification/2026-07-28/changelog ; .../2026-07-28/schema ; .../2026-07-28/server/tools ; .../2026-07-28/server/resources ; .../2026-07-28/server/prompts ; .../2026-07-28/client/elicitation

| Feature | 2026-07-28 status |
|---|---|
| Handshake and sessions | `initialize` and `Mcp-Session-Id` removed. Each request carries protocol version and client capabilities in `_meta`. `server/discover` required. Every result needs `resultType`. |
| Tool annotations | `title`, `readOnlyHint` (default false), `destructiveHint` (default true), `idempotentHint` (default false), `openWorldHint` (default true). Hints only; clients must not trust them from untrusted servers. |
| Structured output | `outputSchema` any JSON Schema 2020-12 keyword; `structuredContent` any JSON value; SHOULD also return serialized JSON in a text block. |
| Resources | `resources/subscribe` replaced by `subscriptions/listen`. List results carry `ttlMs` and `cacheScope`. Not-found -32002 changed to -32602. |
| Prompts | `prompts/list` must not vary per connection. `prompts/get` may return `InputRequiredResult`. |
| Elicitation | Form and URL modes via MRTR: server returns `InputRequiredResult`, client retries with answers. `notifications/elicitation/complete` removed. |
| Sampling | Deprecated (SEP-2577), kept at least 12 months. |
| Roots | Deprecated (SEP-2577). Replacement: directories via tool parameters or server config. |
| Logging | Deprecated. `logging/setLevel` removed; level set per request in `_meta`. |

Not verified in this pass: Cancellation and Progress rows were truncated in the research output.
